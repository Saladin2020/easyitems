# Easy Items — studio usage guide

Items, shops, inventory, loot tables and crafting for 2D games. Agents **write `easyitems/1` JSON, check it, play it
through the simulator and export** a Godot 4.3+ project (Resources, `Items` autoload, shop UI) or a PixiJS v8 runtime.
Icons are drawn from code (44 built-in icons, 24 or 32 px); nothing is generated by AI and nothing calls a network.

Install is local only. Do not push or modify the upstream GitHub repo.

## Paths

| What | Path |
|---|---|
| Install (package 0.1.0, `<SHA>` on master) | `/workspace/indie-studio/tools/easyitems` |
| CLI wrapper | `node /workspace/indie-studio/tools/easyitems-cli.mjs` |
| Studio projects | `/workspace/indie-studio/projects/<Name>/` |
| Format | `/workspace/indie-studio/tools/easyitems/docs/FORMAT.md` |

A game's catalog lives in `/workspace/indie-studio/projects/<Name>/items/*.easyitems.json`, its quests in `quests/`
(Easy Quest `.ezq`, cross-checked), exports in `exports/`. `init --workspace <dir>` once per project copies the
starter catalog (village + raya, 44 items, 3 shops) and two sample quests.

```bash
export EASYITEMS_HOME=/workspace/indie-studio/tools/easyitems
export EASYITEMS_WORKSPACE=/workspace/indie-studio/tools/easyitems
export EASYITEMS_ALLOWED_DIRS=/workspace/indie-studio/projects
```

The wrapper sets these. Ids must match `^[a-z0-9_-]+$`.

## Commands

```bash
W=--workspace=/workspace/indie-studio/projects/<Name>
node …/easyitems-cli.mjs list $W [--tag raya] [--category food] [--json]
node …/easyitems-cli.mjs show kurma $W                 # item + shops that sell it + recipes
node …/easyitems-cli.mjs shops [raya_bazaar] $W         # stock with buy / sell prices
node …/easyitems-cli.mjs icons                          # 44 built-in icon names
node …/easyitems-cli.mjs add-item khanom_tom --th ขนมต้ม --en "Coconut rice balls" --icon kanom_chan --category food --price 12 $W
node …/easyitems-cli.mjs check $W [--quests path.ezq]   # exit 1 on errors
node …/easyitems-cli.mjs render --out icons.png --scale 3 $W
node …/easyitems-cli.mjs loot market_basket --seed 42 --times 3 $W
node …/easyitems-cli.mjs export --preset godot|pixi|png|json|all [--size 32] $W
node …/easyitems-cli.mjs serve $W                       # http://127.0.0.1:8878
```

`export --out DIR` (single preset only) **writes into DIR without deleting it**. `--preset all` cannot take `--out`.

## MCP

`node /workspace/indie-studio/tools/easyitems/dist/mcp/server.js --workspace <dir>` (stdio) or add `--http --port 8879`.
Tools: `workspace_info`, `list_items`, `get_item`, `write_items` (`dryRun`), `check_items`, `render_icons`, `roll_loot`,
`simulate`, `export_items`. Details: `docs/MCP.md` in the install.

## Godot import

Export `--preset godot`, then copy `easyitems/` into the game and add `res://easyitems/easyitems.gd` as the autoload
**`Items`** (the exported `project.godot` shows how). `Items.buy(shop, id)`, `sell`, `use`, `equip`, `craft`,
`loot(table, seed)`, `advance_days`, `to_dict()` / `from_dict()` for saves, signals `changed` and `coins_changed`.
`preload("res://easyitems/shop_ui.tscn")` is a ready shop screen; it uses `res://easyui/themes/teak.tres` when Easy UI is
exported into the same project. `godot --headless --path <export> --script res://test_items.gd` must print `OK`.

## Content rules

Halal shops (`halal: true`) may not stock pork, alcohol or `halal: false` items (`check` fails). No Quran, scripture,
Arabic calligraphy, sacred figures or depictions of the Prophet as items or icons. Keep catalogs multicultural.
