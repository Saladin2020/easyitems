# Easy Suite brand assets

Generated by the Easy Suite brand scripts (`easy-suite-brand/items_v2.py` on top of `suite12_v2.py`). Same frame,
palette and fonts across all thirteen tools; only the icon and accent colour change. Easy Items uses bronze
`#c48a4a` and a cloth pouch with a coin; its banner and social art are a market stall stocked with real Easy Items
icons (Raya bazaar shelf, Thai market shelf, bicycle and gear shelf).

| File | Use |
|---|---|
| `banner-items.png` (1280×320) | README header |
| `social-items.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-items.png` (240×240), `logo-items-48.png`, `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). v2 style: subtle green accent and a light
8-point star (girih) pattern on the teak, cream and gold palette.
